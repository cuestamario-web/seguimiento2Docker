¿La aplicación usa alguna variable de entorno? ¿Cómo se llama?
R/ Usa una variable de entorno llamada NOTA_APROBACION y se lee en evaluacion.py

¿Es Obligatoria? ¿Que pasa si no se define?
R/ No es obligatoria. como se usa o.getenv con un segundo argumento, si la variable no se define la aplicación toma el valor por defecto 3.0 y funciona con normalidad.

¿Que cambia en el resultado si se modifica su valor?
R/ Cambia la nota minima para aprobar, las notas definitivas no cambian, solo el estado
(Aprobado o reprobado) por lo que si aumentamos el valor hay menos aprobados y viceversa.

Si existe, declárala en el Dockerfile con un valor por defecto y
   demuestra con docker run que se puede cambiar sin reconstruir.

La variable está declarada en el Dockerfile con ENV NOTA_APROBACION=3.0.

# Construir la imagen
docker build -t reporte-notas .

# Ejecutar con el valor por defecto (3.0)
docker run --rm reporte-notas

# Ejecutar cambiando la variable sin reconstruir la imagen
docker run --rm -e NOTA_APROBACION=3.5 reporte-notas
