# seguimiento2Docker
Repositorio dedicado para la entrega del segundo seguimiento del corte

En este repositorio encontraran 5 ejercicios cada uno con su respectivo enunciado , deben abordar cada uno de los ejercicios sobre la creación de dockerfiles y cargar las respuestas a este mismo reposiorio

***** PASOS para la entrega *****
1. Clonar el repositorio
2. Crear una rama propia.
3. Luego de tener los cambios listos debes realizar el push de tu rama usando el parametro -u.

El plazo de entrega y la forma de entregar esta establecido en el Moodle.
